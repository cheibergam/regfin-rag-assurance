# regfin-rag-assurance
An evaluation framework for measuring the faithfulness, auditability and compliance of RAG systems in UK regulated financial services. Benchmarks citation accuracy, hallucination and abstention behaviour, using Financial Ombudsman Service decisions as the first case study.
FOS decisions are not redistributed here due to copyright restrictions. Each evaluation item references its corresponding decision by the DRN number in the grounding field. To access the decisions, please search for the DRN in the official FOS database: [search link]."

Note on the rationale: This transforms the absence of PDFs from a "gap" into a "correct and documented methodological choice"—once again, the kind of rigour that impresses.
